# RegTranslate

AI-powered tool that converts regulatory documents (HIPAA, GDPR, ADA/WCAG, FDA 21 CFR Part 11) into developer-ready tasks exportable to Jira/GitHub.

**Demo:** [regtranslate.vercel.app](https://regtranslate.vercel.app)

---

- Upload PDFs → AI extracts implementation tasks with citations
- Review, edit, filter by priority
- Export to Jira, GitHub Issues, or CSV

For setup, architecture, and deployment: see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) and [DEPLOYMENT.md](DEPLOYMENT.md).
